# MewLink

Interactive prototype of MewLink, a care coordination tool for community cat caregivers in Singapore.

## Live demo
https://moonlit-semifreddo-975f1d.netlify.app/#today

## Screens
Today, Cats, Community, Ask Mew, Tiger's profile, help thread, outreach review, care update flow, photo upload, memory editor.

## Design principles
- Observations are saved as written.
- AI output is a draft until a person approves it.
- No automatic diagnosis.
- Only general areas are shown, never exact locations.
- Content is visible to circle members only.
- Original photos and records are never altered.
